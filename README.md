# GomokuAI-TrainWhl

基于 NumPy 的轻量化遗传五子棋模型训练。

## 自博弈训练

训练器使用当前种群和历史策略池进行对弈。每代最优策略之外，还会将该代的高适应度策略存入有限大小的历史池；评估时按 `historical_opponent_probability` 随机选择历史对手，帮助减少对当前种群的过拟合。适应度结合胜率与对手强度校正后的 Elo 分数，`elo_weight` 用于调节 Elo 的权重。最优个体会以精英方式直接保留到下一代，自适应变异会在种群多样性降低时提高变异强度。

`test.py` 中通过 `winner_after_move_func` 使用只检查最后一手的快速胜负检测，并以 `simulation_budget=0` 关闭额外前瞻模拟；候选棋盘也会批量构造。关闭前瞻会缩短训练时间，但可能降低每步选择的搜索深度。需要更强的搜索时，可提高 `simulation_budget`，或不传 `winner_after_move_func` 以回退到通用胜负检测。

网络前向传播包含两层卷积和池化，卷积输出展平后接入全连接网络。当前 Gomoku 评估以胜、负、和与 Elo 为目标；由于棋局没有资源积累等中间目标，暂不添加任意中间奖励，避免塑造出与获胜目标冲突的行为。
